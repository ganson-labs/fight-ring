# Звуки ринга

Собраны `node scripts/build-sounds.mjs` из `scripts/sounds.sources.json`: тишина по краям обрезана, пик звуков −2 dBFS, края с плавным входом 3 мс и затуханием до 60 мс, петли фона и музыки — бесшовные (хвост перетекает в начало), громкость петель по RMS (фон −21 dBFS, музыка −18 dBFS). Opus в Ogg: звуки моно 96 кбит/с, петли стерео 128 кбит/с. Каталог с уровнями в миксе — `catalog.js`, имена для `moves.json → sounds` печатает `node arena/cli.mjs sounds`.

Источники: звуки из сторонних библиотек (Pixabay, Sonniss #GameAudioGDC, Mixkit; источник и лицензия каждого файла — в таблице) и звуки, сгенерированные для ринга через ElevenLabs. Исходные файлы в репозиторий не входят. Все лицензии разрешают звук в играх, роликах и коммерческих проектах без указания автора; продавать или раздавать сами звуки отдельной библиотекой нельзя.
