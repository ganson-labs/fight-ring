# Матч

Матч идёт между двумя участниками до двух побед. Между раундами каждая модель получает материалы прошедшего раунда и время на доработку бойца: это называется раздевалкой. Как завести участников, описано в [contestants.md](contestants.md).

## Команды

```
node ring.mjs match new final --red red --blue blue --stage rooftop,server,foundry --minutes 20
node ring.mjs match round final        # раунд 1: снимок бойцов, бой, ролик 16:9, раздевалка обоим
#   дать обоим участникам prompts/locker.md на 20 минут
node ring.mjs match round final        # раунд 2, стороны меняются
node ring.mjs match status final
node ring.mjs match changes final red  # что участник поменял между раундами и что сказал в раздевалке
node ring.mjs match notes final        # собрать заново ответы раздевалки из журналов агентов
node ring.mjs match render final --round 3 --vertical   # ролик раунда 9:16
node ring.mjs match render final --round 3 --ads        # ролик раунда с рекламными заготовками
```

## Правила матча

Побеждает тот, кто первым выиграл два раунда; другое число задаёт ключ `--first-to`. Ничья не засчитывается: на экране следующий раунд идёт под тем же номером с пометкой «переигровка», а при счёте 1:1 он называется решающим. В матче не больше пяти раундов. Стороны меняются каждый раунд. Сцены идут по списку из ключа `--stage`.

Перед раундом судья копирует папку `fighter/` каждого участника в `matches/<матч>/round-N/<id>/fighter` вместе со своей копией движка (`arena/engine`). Это снимок версии бойца на раунд. Рядом в `match.json` записывается состояние git участника: номер коммита и признак незакоммиченных правок. Бой считается в Node движком судьи. Запись боя лежит в `round-N/replay.json`, разбор лежит в `analysis.json`, ролики лежат в `fight-16x9.mp4` и `fight-9x16.mp4`.

Папка `matches/` в git не попадает: это рабочие файлы судьи. В репозиторий законченный турнир переносит команда `publish`, она описана в [seasons-and-site.md](seasons-and-site.md).

## Раздевалка

После раунда судья кладёт в папку каждого участника материалы в `history/round-N/`. Там лежат итог раунда `result.md`, ролик `fight.mp4`, кадры `frames/`, ход боя `timeline.md`, запись `fight.json`, собственная сводка участника `report.md` и `report.json` (чем попадал, что пропустил, где промахивался) и карточка соперника `opponent.md` и `opponent.json` (имя, характеристики, приёмы с цифрами и то, как их видят мозги). Кода соперника и его правок там нет. Для участника это описано в `kit/ARENA.md` в разделе «Матч и раздевалка».

Ответ модели из раздевалки судья берёт из журнала агента: это последнее сообщение модели после промпта «Раунд N окончен». Ответ кладётся в `round-N/<id>/locker.json` следующего раунда.

## Статистика

После каждого раунда судья считает статистику: здоровье обоих бойцов по времени, попадания, блоки, парирования, броски, суперприёмы, лучшую серию, моменты боя и то, как изменились показатели после правки в раздевалке. Она лежит в `round-N/stats.json` и в `stats.json` матча, заново её считает `node ring.mjs match stats <матч>`. Ролик раунда получает разметку кадров `fight-16x9.timing.json`: тик боя каждого кадра, фазы показа, реплики и звуки.

## Протокол и проверка записи

```
node ring.mjs match verify final      # переиграть каждый раунд на снимке движка и сравнить с записью
node ring.mjs match protocol final    # то же и протокол матча
```

Протокол (`judge/protocol.js`) записывает версию ринга из `kit/arena/engine/version.js`, модель и её идентификатор, агента, силу рассуждения, время работы на сборку и на каждую раздевалку и расход токенов из журналов агента. Стоимость записывается, если журнал её содержит. Картинки и секунды голоса берутся из учёта ринга.

Каждый раунд переигрывается на снимке движка этого раунда и сверяется с записью по хэшу боя. Движок самодостаточен, поэтому старый матч проигрывается одинаково и после изменения движка в ринге. Тест `tests/protocol.test.mjs` держит это на записи ринга 2.0 из `tests/fixtures/match-2.0`.

## Подписи и шпаргалка для озвучки

Ролик матча озвучивает человек, поэтому факты о матче идут на экран подписями и в текстовую шпаргалку (`judge/captions.js`, промпт `prompts/commentator.md`).

Судья выбирает места для подписей: раздевалка в начале раунда, серии, камбэки, нокауты, новое из раздевалки, суперприёмы. Подпись ставится одна за раз, не чаще одной на 7 секунд, на 3–4 секунды, плашкой в стиле экрана VS. Слова подписей и шпаргалку пишет Claude Code в режиме `-p` по фактам матча, в пустой папке и без инструментов. Ответ хранится в `matches/<матч>/comment/wording.json` и берётся снова, пока факты те же. С ключом `--no-model` или если модель не ответила, подписи пишутся словами судьи.

Шпаргалка `reel/notes-for-voice.md` рассказывает по раундам, что произошло, что каждая модель изменила в раздевалке и её слова дословно, даёт 5–7 лучших моментов с таймкодами и фразой к каждому и список подписей на экране. Та же история для зрителя лежит в `matches/<матч>/story.json`, её читает вкладка «История» в игре. В ролики раундов подписи не попадают: эти ролики уходят участникам в раздевалку.

## Озвучка комментаторами

```
node ring.mjs match comment final [--round N] [--budget 30]
```

Озвучка по умолчанию выключена (`judge/commentator.js`, промпт `prompts/commentator-voice.md`). Два голоса ElevenLabs, ведущий и эксперт из `commentator/voices.json`, говорят только в паузах раунда: до боя, после нокаута и на итоге. Каждая реплика законченная, поверх бойцов и ведущего ринга они не говорят, игра под речью приглушается. В файле `round-N/fight-16x9-comment.mp4` первая дорожка идёт без озвучки, вторая с ней. В ролик матча озвучка попадает только с ключом `match reel --comment`. Реплики лежат в `round-N/comment/lines.json`, расход записывается в `ledger/commentator.json`.

## Ролик матча

```
node ring.mjs match reel final [--shorts 3] [--no-captions] [--comment] [--no-model]
```

Ролик матча (`judge/reel.js`) состоит из экрана VS первого раунда, лучших моментов каждого раунда, экрана раздевалки у тех, кто менял бойца, экрана итога раунда и финала с повтором нокаута. Лучшие моменты выбираются так: суперприёмы, последний удар, самая длинная серия, камбэк по графику здоровья, первое применение того, что добавила раздевалка, и самый сильный удар; сначала по одному каждого вида, потом лучшие из оставшихся.

Экраны между раундами те же, что в игре (`viewer/game/screens.js`, `viewer/screens.css`). Страница `viewer/card.html` с параметром `rec=1` держит экран неподвижно, и судья снимает его покадрово.

Вместе с роликом собираются шортсы 9:16 по 20–40 секунд: лучшие моменты матча, решающий раунд, раздевалка и что она дала. Чистый ролик без подписей всегда лежит рядом как `match-16x9-clean.mp4`. В `reel/pieces/` каждый кусок лежит отдельно, файлы `moments.json` и `moments.md` содержат таймкоды исходных роликов раундов.

Ключ `--studio` дополнительно отправляет ролик в программу монтажа автора проекта (команда `vagent`). Эта программа в репозиторий не входит, без неё ключ не работает.

## Пакет для монтажа

```
node ring.mjs match pack final [--no-render]
```

Пакет (`judge/pack.js`) собирается из папки матча в `matches/<матч>/pack/`, даже когда участников уже нет в реестре. В нём семь папок:

- `01-rounds` содержит каждый раунд 1080p с частотой 60 кадров, чистым и с подписями судьи;
- `02-screens` содержит экран VS, итог каждого раунда, каждую раздевалку (16:9 и 9:16) и финал отдельными роликами;
- `03-fighters` содержит каждую версию каждого бойца: фигуры PNG с прозрачным фоном в нескольких позах, лист поз, части тела и картинки модели;
- `04-lockers` содержит правки раздевалок (`git diff` снимков) и слова моделей;
- `05-stats` содержит время, токены, деньги, картинки, голос, здоровье по времени и счётчики раундов в CSV и JSON;
- `06-thoughts` содержит «мысли бойцов» (`judge/thoughts.js`): что боец решил в каждый момент, восстановленное из того, что он сделал в бою, с субтитрами SRT;
- `07-reel` содержит ролик матча, если он собран.

Файл `README.md` в пакете перечисляет каждый файл. Ролики раундов судья снимает на движке снимка раунда, поэтому старый матч переснимается тем же боем и после изменения движка.

## Призрак

```
node ring.mjs match ghost final --round 2 --cid red --moment super
```

Команда делает короткий ролик: кусок раунда, поверх которого полупрозрачно показана версия бойца до раздевалки. От состояния выбранного тика её мозги играют дальше против того же соперника. Так видно, что изменила раздевалка.
